Project Summary: PlayPointy.com
Complete planning document — basis for Cursor prompt and Content Playbook

1. Project Overview
A mobile-first browser card game for groups. No download needed. Goal is viral growth. Internationally accessible, must stay cost-efficient even at very high traffic. 99% of users will play on mobile. The game is a "Who is more likely to" format — one phone for the whole group, no account needed for the free starter pack.

2. Technical Architecture

Deployment Flow
Cursor → GitHub → Cloudflare Pages (auto-deploys on every code change)
Framework
Next.js — works perfectly with Cloudflare Pages, handles routing cleanly, Cursor knows it well.
Card Data Structure
All cards are static (same for all users). Managed in a single cards.json file in the project. Each card has its own cardColor hex code which controls the card background, pack name color, and both button colors simultaneously. Share tokens are randomized and generated by Cursor at build time. The pack field must match exactly the id field in packs.json.
{
  "cards": [
    {
      "id": 1,
      "pack": "fun_pack",
      "packName": "Fun Pack",
      "cardColor": "#FF6B6B",
      "title": "Drink Mojito at the Beach?",
      "image": "card_001.webp",
      "shareToken": "x7kQ9mPvR2"
    }
  ]
}
Pack Data Structure
{
  "packs": [
    {
      "id": "fun_pack",
      "name": "Fun Pack",
      "price": 2.99,
      "sortOrder": 1,
      "preview_images": ["fun_preview_1.webp", "fun_preview_2.webp", "fun_preview_3.webp"]
    }
  ]
}
Pack preview images are custom-designed landscape banner images, full screen width, created in Photoshop, uploaded to R2
Newest pack always has lowest sortOrder — appears at top of store
Both JSON files will have clear comments added by Cursor explaining every field
R2 Image URL Structure
https://r2.playpointy.com/cards/card_001.webp https://r2.playpointy.com/packs/fun_preview_1.webp

6. Game Flow
User opens link → first card immediately, no loading screen
30 cards in free pack, randomized every session
Swipe left (next) or swipe right (previous)
After free pack card 30: automatic redirect to store
Multiple packs active = all cards shuffled together
Always starts fresh but remembers which packs are active
Minimum one pack always active — last toggle cannot be turned off ("At least one pack must be active")
Portrait mode only — landscape locked
All 150 cards finished: "You've played all cards — more packs coming soon! 🙂" + "Reshuffle" button
Shared Premium Card Flow
Non-buyer opens shared premium card link
Sees that card normally — no wall, no blur
Swipes → seamlessly into free starter pack from card 1
After card 30 → store User never knows the card was premium.

21. Content & Marketing System
Full detail in separate Content Playbook document.
Brand Mascot — The Guy
One male cartoon character — permanent face of PlayPointy on all social media
Selected from existing illustrations: universally relatable age (25-32), distinctive at thumbnail size, expressive face, likeable underdog energy, nationality ambiguity
Always gets pointed at — the running gag that builds over hundreds of videos
Voice: founder's real voice — genuine personality cannot be faked by AI
Clothing rotation possible later for freshness
The Video Format
Three shots. One template. Infinite cards.

The storytelling structure:
Card is NEVER shown first
Character tells 10-12 second funny anecdote in first person
Card appears at end as the punchline
Hands slide in pointing at him
"...of course. PlayPointy.com. Send this to that friend."
Mouth Animation
South Park style open/close flap — driven automatically by HeyGen with voice audio. HeyGen also adds subtle head movement and blinking automatically.
Character Expression Library
Same source image per character fed to Midjourney for each expression = perfect consistency across all videos. Suggested expressions: guilty, shocked, horrified, laughing, embarrassed, smug, nervous, resigned.
Production Stack

Per video: ~25-30 minutes once template is built.
Algorithm Strategy
Storytelling format has highest TikTok completion rates — viewer cannot disengage mid-story
Post in niche series to seed multiple algorithm tracks: couples, friend groups, pregame, dark humor, office
Each pack has its own content series targeting a different audience
Shares are strongest algorithmic signal
Boost best clips with €100/month
Minimum 3 videos per week for 3 months before judging traction
Pin gameplay explanation video to profile top permanently
Platforms
TikTok — primary
Instagram Reels — same content, remove TikTok watermark
YouTube Shorts — secondary, longest shelf life
